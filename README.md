## About Me

I'm an Information Technology student at **Hanoi University of Architecture (HAU)**, focused on **Artificial Intelligence**, **Full-Stack Development**, and **Software Engineering**.

I build software that solves real-world problems by combining intelligent algorithms with scalable system architecture — with particular interest in applying AI to the **Architecture, Engineering & Construction (AEC)** industry.

- 🔭 Currently building **AI-powered applications for the AEC industry**
- 🧠 Exploring **Computer Vision** and applied ML
- 🛠️ Working with **FastAPI, PostgreSQL, and Docker-based deployment**
- 📚 Learning **LLMs, RAG, LangChain/LangGraph, Kubernetes, and Microservices**
